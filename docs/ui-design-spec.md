## 风格调研摘要

### 视觉风格

- **名称：** 飞书风企业工作台
- **来源：** 竞品方案 D（飞书蓝白气质 + Dify 会话结构 + 本 Demo 右栏事件流）
- **特征：** 宽屏桌面优先、信息密度高但整洁；白底 + 浅灰工作区 + 飞书蓝强调色；8px 圆角；细分割线；无营销大渐变、无 AI 粒子、无玻璃拟态堆叠
- **气质：** 员工在飞书里打开助手后的办公界面，不是 ChatGPT 营销页，也不是开发者调试 IDE

### 字体搭配

- 标题：Outfit，字距 -0.04em（Logo 与页面标题）
- 正文与数据：系统中文优先「PingFang SC / Noto Sans SC」，西文与技术字段 Geist / Inter
- 界面可见文案以中文为主；事件名、路由值、技能 ID 等技术字段可保留英文，须配中文释义

### 关键 UX 规则

1. **三栏工作台固定视口高度**：左会话、中对话、右事件流各自独立滚动，互不撑高整页。
2. **事件流是时间线，不是流程图**：按发生顺序追加节点；未执行的步骤不占位、不灰显「跳过」。
3. **状态比装饰重要**：待澄清、待确认、未知、拒答必须用文案 + 色标同时表达，禁止只靠图标。
4. **写操作先确认**：确认卡是中栏一等公民；未确认不得出现「会议已创建」。
5. **不发明入口**：员工正式导航只保留「对话」和最近会话；评测对照不是员工功能，不得做进左侧导航。不做附件、深度思考、设置及其他原型多余频道。员工侧唯一过程信息是右侧当前轮事件流。

### 布局结构

- **整体布局：** 顶栏 + 下方三栏（左 280px / 中弹性 / 右 360px），总高度 100vh
- **顶栏：** 左侧 Logo「Aily」+ 副文案「企业智能助手」；中部搜索框占位但 **MVP 不提供搜索功能**（禁用，避免范围扩张）；右侧仅身份（头像、林小北、产品部）。不做帮助、通知铃（原型有、规格无）
- **左侧：** 主导航仅「对话」（当前页高亮）；其下「新建对话」；再下「最近对话」列表。不做评测与案例、工作助手/知识库/会议助手/内容生成/我的任务/设置
- **中栏：** 顶部五个快捷入口（知识问答、创建会议、生成周报、查询信息、执行任务）→ 消息流 → 输入框
- **右栏：** 默认「过程」页签为事件流；知识问答成功时可切「相关来源」。不做「更多信息」页签

### 组件清单

| 区域 | 组件类型 | 内容/数据 | 交互行为 |
|------|---------|----------|---------|
| 顶栏 | 品牌 + 身份 | Aily 企业智能助手；林小北｜产品部 | 身份不可点击切换账号 |
| 顶栏搜索 | 禁用输入框 | 占位「搜索对话、文档或功能」 | Disabled，不提交 |
| 左导航 | 文本导航 | 对话 | 当前页高亮；无其他员工导航项 |
| 新建对话 | 主按钮 | 新建对话 | 清空中栏与右栏为新上下文 |
| 最近对话 | 列表项 | 标题 + 时间 | 点击切换；当前项 Primary Soft 底 |
| 快捷入口 | 五个等宽操作卡片 | 知识问答 / 创建会议 / 生成周报 / 查询信息 / 执行任务 | 向输入框填入对应演示问句或直接发起来源 Feature 的主触发；执行任务与创建会议同一链 |
| 用户气泡 | 右对齐消息 | 员工问句 | 只读 |
| 助手气泡 | 左对齐消息 | 答案、拒答、澄清、确认卡、工具结果、周报 | 按本轮类型渲染 |
| 引用块 | 编号列表 | 文档名、章节、打开文档（MVP 打开来源抽屉即可，不外链真实文件） | 与右栏来源同源 |
| 制度表格 | 数据表 | 职级 / 城市类型 / 住宿标准 | 只读 |
| 澄清选项 | 选项按钮 | 如两名张明 | 点选后作为补全发送 |
| 确认卡 | 摘要卡 + 同意/取消 | 会议时间、参会人、主题、时长、类型 | 同意才进入创建；取消不创建；关键字段改后此卡标记已作废 |
| 未知横幅 | 警告条 | 创建结果未知，需要核验 | 禁止同时出现成功文案 |
| 周报编辑区 | 多行文本 | 生成的周报 | 可编辑，失焦或点「保留修改」后以编辑版为准 |
| 输入框 | 多行输入 + 发送 | 请输入，或选择上方功能 | 发送开启一轮提问；无附件、无深度思考 |
| 事件流 | 时间线 | 时间戳 + 中文步骤名 + 关键字段 | 只追加真实节点；节点可展开看原文/改写/槽位等 |
| 过程页签 | 两个页签 | 过程、相关来源 | 来源仅在有引用时有内容，否则空状态「本轮无知识来源」 |
