# F-002 完成企业知识问答功能规格

## 1. 功能身份

- Feature ID：F-002
- 功能名称：完成企业知识问答
- 所属版本：MVP
- 主要角色：员工（R-001）
- 来源需求：S-001、S-002、BR-001、BR-002、BR-013
- 依赖 Feature：F-001
- 对应页面/视图候选：对话工作台（中栏消息 + 右栏事件流 + 来源）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

员工询问企业制度时：有可靠知识则得到带引用的答案；无可靠依据则拒答，不编造、不假引用。本轮真实步骤按时间出现在事件流中。

## 3. 前置条件与触发条件

- 前置条件：当前对话已存在（F-001）；预置差旅等企业知识条目可用
- 触发条件：员工在当前对话输入制度类问题，或使用知识问答快捷入口后发出问句；主演示问句为「公司的差旅住宿标准是什么？」

## 4. 功能范围

### 包含

- 有据回答：答案中的职级/城市类型/限额等关键数字可对上引用片段
- 引用：文档名、章节、原文片段；中栏与来源视图数据同源
- 拒答：未找到可靠企业知识依据时明确拒绝
- 本轮事件流：问题改写、意图、路由到知识、检索、引用核验、最终结果等实际发生的步骤
- 只读：不出现写操作确认

### 不包含

- 知识上传、删除、切片治理
- 标准问答库运营后台
- 创建会议、周报、会议室查询
- 开放式模型闲聊充当制度

## 5. 主流程

1. 员工在当前对话提出差旅住宿标准问题。
2. 系统理解为本轮企业制度咨询，路由到企业知识。
3. 检索到可引用条目后生成答案，附上文档名、章节、原文片段。
4. 本轮提问进入已回复；事件流按时间追加真实步骤，不出现未执行的写确认节点。

## 6. 异常与边界流程

- 预置无依据问句：进入已拒答，文案表明未找到可靠企业知识依据，不出现虚构制度和假引用。
- 检索到片段但无法支撑关键数字：不得作为成功有据回答，按拒答处理。
- 本轮为只读：事件流不得出现确认单或「会议已创建」。

## 7. 业务规则与不变量

- BR-001：无可靠依据不得生成制度答案，不得伪造引用
- BR-002：关键数字和条款必须能对应到本轮引用片段
- BR-013：事件流只记录真实发生的步骤

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 企业知识条目 | 作为回答依据 | 预置 |
| 创建 | 一轮提问、意图、路由决定、事件 | 记录本轮知识问答 | F-002 |
| 创建 | 引用 | 附在有据回答上 | F-002 |
| 修改 | 一轮提问 | 已回复或已拒答 | F-002 |

## 9. 权限、隐私与安全约束

- 知识只读；员工不能改制度原文。
- 答案不得泄露预置知识以外的虚构内部数据。

## 10. 外部服务与降级边界

- 依赖服务：企业知识以预置条目提供；措辞可用 Mock，不依赖真实模型验收
- 完整验收需要的权限：无
- 缺失时允许的降级：无预置知识时只能拒答
- 降级时不得宣称：不得宣称已连接飞书知识库或真实检索服务；不得用无引用的生成文字冒充有据回答

## 11. 验收标准

### AC-F002-01 差旅标准有据作答并带引用

- Given：当前对话已打开，差旅制度知识可用
- When：员工发送「公司的差旅住宿标准是什么？」
- Then：回答含职级、城市类型与限额，数字能对上至少一条引用（文档名、章节、原文片段）；本轮为已回复
- 验证类型：agent

### AC-F002-02 无可靠依据时拒答

- Given：当前对话已打开，使用预置无依据问句
- When：员工发送该问句
- Then：得到未找到可靠企业知识依据的拒答；不出现虚构制度条款，不出现假引用
- 验证类型：agent

### AC-F002-03 只读知识问答的事件流

- Given：员工刚完成一次有据知识问答
- When：员工查看本轮事件流
- Then：事件按时间追加，可见改写、意图、路由到知识、检索、引用核验、最终结果等实际步骤；不出现写操作确认节点
- 验证类型：agent

### AC-F002-04 引用与来源一致

- Given：一次有据回答已展示引用
- When：员工查看引用来源
- Then：来源中的文档与片段与中栏引用指向同一批依据，不出现中栏有、来源无的关键数字
- 验证类型：agent
