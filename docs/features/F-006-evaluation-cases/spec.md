# F-006 评测与 Bad Case 对照（Demo Validation）

## 1. 功能身份

- Feature ID：F-006
- 功能名称：评测与 Bad Case 对照
- 类型：Demo Validation Capability / Internal Demo Tool（**不计入员工侧 MVP 产品 Feature**）
- 所属版本：Demo Harness
- 主要角色：R-002 Demo 操作者
- 来源需求：S-008、BR-016、BR-013
- 依赖 Feature：无（不进入员工产品依赖链）
- 对应页面/视图候选：独立验证台 `/demo/evaluation`；也可由顶部「原型场景切换（非产品功能）」进入
- Spec 状态：Ready
- Spec 版本：2

## 2. 用户结果

Demo 操作者在非产品验证台用少量预置案例对照预期路由与实际路由、是否通过、Bad Case 分类，并可回放事件流。验证操作不写入企业知识，也不直接创建成功会议。员工工作台看不到本能力的任何入口或评测字段。

## 3. 前置条件与触发条件

- 前置条件：预置评测案例已存在，覆盖有据问答、拒答、创建会议成功、超时未知、确认作废、周报、会议室查询
- 触发条件：操作者从原型场景切换条或独立路径 `/demo/evaluation` 进入；**不得**从员工工作台正式导航进入

## 4. 功能范围

### 包含

- 验证台显著标注「Demo Validation / 非产品功能」，视觉上不得伪装成员工功能
- 案例列表：名称、预期路由、实际路由、通过/不通过、Bad Case 分类
- 打开单条案例查看对应事件流回放
- 用预置 Fixture 稳定复现对照结果

### 不包含

- 员工工作台左侧正式导航中的「评测与案例」
- 员工正常流程中的预期路由、实际路由、通过/不通过、Bad Case 分类、评测案例列表
- 生产级评测集、自动标注、千级回归平台
- 在验证台直接创建成功会议或修改企业知识

## 5. 主流程

1. 操作者经非产品入口打开验证台，看到「Demo Validation / 非产品功能」标注。
2. 看到预置案例的预期路由、实际路由、通过或不通过、分类。
3. 打开其中一条，看到该案例的事件流回放。
4. 关闭后企业知识与会议数据不因本次验证而产生新的成功创建。

## 6. 异常与边界流程

- 案例实际路由与预期不一致：标记为不通过，仍展示两侧路由和事件流，不得改写成通过。
- 反复打开同一案例：对照结果稳定。
- 超时与确认作废案例必须可区分分类，且回放中不得把超时显示为会议已创建。
- 员工打开工作台：左侧只有「对话」与最近会话，无评测入口。

## 7. 业务规则与不变量

- BR-016：评测只存在于 Demo 验证台；不写知识、不直接创建会议；不得出现在员工正式导航或员工正常流程
- BR-013：回放事件流只包含该案例真实发生过的步骤
- 员工侧唯一过程信息是工作台右侧当前轮 Agent 事件流，不是本验证台
- 预置案例须覆盖 S-001～S-007 对应的路由类型

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 评测案例 | 列表与详情对照 | F-006 |
| 读取 | 事件 | 回放该案例事件流 | 产生该轮的产品 Feature / 预置 |
| 创建 | 无 | 验证不创建会议或知识 | — |
| 修改 | 无 | 不改案例预期、不写知识 | — |

## 9. 权限、隐私与安全约束

- 验证台不是员工权限扩展，不授予改 Pipeline 的能力。
- 回放不得展开与案例无关的他人完整日程。

## 10. 外部服务与降级边界

- 依赖服务：预置案例 Fixture；不依赖真实评测平台
- 完整验收需要的权限：无
- 缺失时允许的降级：无案例则验证台应明确无数据，不得伪造通过率
- 降级时不得宣称：不得宣称已跑通大规模评测或生产回归；不得把验证台称为员工功能

## 11. 验收标准

### AC-F006-01 验证台展示路由对照

- Given：预置评测案例已加载，操作者经非产品入口打开验证台
- When：查看案例列表
- Then：页面标注「Demo Validation / 非产品功能」；每条案例可见预期路由、实际路由、通过或不通过；至少能区分超时未知与确认失效两类 Bad Case
- 验证类型：agent

### AC-F006-02 打开案例可见事件流回放

- Given：列表中存在一条知识问答或创建会议案例
- When：操作者打开该案例
- Then：能看到对应该轮的事件流；未发生的步骤不出现
- 验证类型：agent

### AC-F006-03 验证不产生成功会议

- Given：操作者打开超时或确认作废案例并查看回放
- When：验证操作结束
- Then：不因此产生新的「会议已创建」业务结果；超时案例回放中不出现会议已创建
- 验证类型：auto

### AC-F006-04 案例覆盖主链且结果稳定

- Given：同一批预置案例
- When：操作者连续两次打开验证台列表
- Then：案例集合覆盖有据问答、拒答、创建会议、周报、会议室查询、超时、确认作废；两次对照结果一致
- 验证类型：auto

### AC-F006-05 员工工作台不出现评测产品入口

- Given：员工处于对话工作台
- When：查看左侧正式导航与主流程界面
- Then：没有「评测与案例」导航；看不到预期路由、实际路由、通过/不通过、Bad Case 分类、评测案例列表；右侧仅本轮事件流（及知识问答时的相关来源）
- 验证类型：agent
