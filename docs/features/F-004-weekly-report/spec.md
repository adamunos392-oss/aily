# F-004 生成并修改本周周报功能规格

## 1. 功能身份

- Feature ID：F-004
- 功能名称：生成并修改本周周报
- 所属版本：MVP
- 主要角色：员工（R-001）
- 来源需求：S-004、BR-009、BR-010、BR-017
- 依赖 Feature：F-001
- 对应页面/视图候选：对话工作台（中栏周报草稿 + 右栏事件流）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

员工请求生成本周周报后，得到一份可编辑周报：事项来自本轮取到的工作消息，闲聊不出现，长期偏好只影响模板/语言/篇幅；员工修改后以编辑版为准。

## 3. 前置条件与触发条件

- 前置条件：当前对话已存在（F-001）；预置本周工作消息（含闲聊与工作事项）；林小北有稳定偏好（简洁、中文、偏事项列表）
- 触发条件：员工发送「帮我生成本周周报」，或使用生成周报快捷入口

## 4. 功能范围

### 包含

- 命中周报技能并展示技能名称与说明
- 固定顺序：取本周消息 → 过滤闲聊 → 提取工作事项 → 套偏好模板 → 润色 → 输出周报
- 员工编辑周报正文，修改后以员工版本为准
- 本轮事件流展示技能命中及上述实际执行步骤

### 不包含

- 跨周汇总、多模板市场
- 用长期记忆编造本周工作事实
- 真实即时消息接入作为验收条件
- 把周报自动发到群或邮件

## 5. 主流程

1. 员工请求生成本周周报。
2. 系统命中周报技能，按固定顺序取消息、过滤闲聊、抽取事项、套林小北偏好、润色。
3. 中栏展示可编辑周报；事件流记录技能名与实际步骤。
4. 员工修改正文后，展示以员工编辑版为准。

## 6. 异常与边界流程

- 预置消息里的闲聊：不得出现在周报事项中。
- 周报中出现预置工作消息里没有的「本周事实」：不合格。
- 员工未修改：保持生成稿。
- 本轮不是写日历：不要求会议确认单。

## 7. 业务规则与不变量

- BR-009：工作事实必须来自本轮工作消息；长期记忆只提供模板、语言、篇幅
- BR-010：闲聊不得进入周报事项
- BR-013：事件流只记录真实发生步骤
- BR-017：员工修改后以编辑版为准，不得悄悄改回生成稿冒充终稿

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 工作消息、演示身份稳定偏好、技能 | 取事实与格式偏好 | 预置 / 平台注入 |
| 创建 | 一轮提问、周报草稿、事件 | 生成本轮周报 | F-004 |
| 修改 | 周报草稿 | 员工编辑后覆盖为编辑版 | F-004 |

## 9. 权限、隐私与安全约束

- 只使用预置给当前身份的本周消息，不拉取他人消息。
- 周报不得写入未提供的他人绩效或薪资等信息。

## 10. 外部服务与降级边界

- 依赖服务：工作消息与润色均为 Mock；不依赖真实模型验收
- 完整验收需要的权限：无
- 缺失时允许的降级：无预置消息则不得生成含具体工作事实的周报
- 降级时不得宣称：不得宣称已同步真实聊天记录；不得把空事实周报说成已完成本周工作汇总

## 11. 验收标准

### AC-F004-01 生成本周周报且命中技能

- Given：当前对话已打开，本周消息已预置
- When：员工发送「帮我生成本周周报」
- Then：中栏出现周报草稿；能看到周报技能的名称与说明；事件流含该技能及取消息、过滤、抽取、套模板、润色等实际步骤
- 验证类型：agent

### AC-F004-02 事实来自本轮消息且不含闲聊

- Given：预置消息同时包含工作事项和闲聊
- When：周报生成完成
- Then：周报事项都能在本轮工作消息中找到对应事实；闲聊内容不出现在周报事项中；不出现消息里没有的本周工作事实
- 验证类型：agent

### AC-F004-03 偏好只影响格式

- Given：林小北稳定偏好为简洁、中文、偏事项列表
- When：周报生成完成
- Then：周报呈现为中文、偏事项列表的简洁稿，且其中事实仍全部来自本轮工作消息
- 验证类型：agent

### AC-F004-04 员工修改后以编辑版为准

- Given：周报草稿已生成
- When：员工修改正文并确认保留
- Then：之后展示的是员工编辑版，而不是改回未编辑的生成稿
- 验证类型：agent
