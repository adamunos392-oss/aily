# F-005 查询可用会议室功能规格

## 1. 功能身份

- Feature ID：F-005
- 功能名称：查询可用会议室
- 所属版本：MVP
- 主要角色：员工（R-001）
- 来源需求：S-005、BR-011
- 依赖 Feature：F-001
- 对应页面/视图候选：对话工作台（中栏查询结果 + 右栏事件流）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

员工查询明天下午 3 点以后可用的会议室，得到只读查询结果；不出现写操作确认，也不创建会议。

## 3. 前置条件与触发条件

- 前置条件：当前对话已存在（F-001）；预置会议室占用与空闲结果
- 触发条件：员工使用「查询信息」入口或发送「查询明天下午 3 点以后可用的会议室」

## 4. 功能范围

### 包含

- 一条只读会议室查询
- 展示预置的可用会议室结果
- 本轮事件流显示只读查询相关实际步骤，不出现确认单

### 不包含

- 预定会议室、创建会议（F-003）
- 多数据源、订阅、复杂分析
- 天气或其他实时信息种类

## 5. 主流程

1. 员工发出会议室查询（快捷入口或固定问句）。
2. 系统识别为只读查询，调用查询类原子能力拿到预置结果。
3. 中栏展示可用会议室；本轮已回复；事件流追加只读查询步骤。

## 6. 异常与边界流程

- 该问句不得走创建会议技能，不得弹出写操作确认。
- 预置无可用会议室：明确告知无可用结果，仍不得创建会议。
- 员工随后说「帮我订这间」：不属于本 Feature；不得在本 Feature 内直接创建会议。

## 7. 业务规则与不变量

- BR-011：查询信息是只读，不走写操作确认，也不走创建会议
- BR-013：事件流只记录真实发生步骤

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 原子能力（会议室查询） | 取预置空闲结果 | 预置 |
| 创建 | 一轮提问、意图、路由决定、事件 | 记录本轮只读查询 | F-005 |
| 修改 | 一轮提问 | 已回复 | F-005 |

## 9. 权限、隐私与安全约束

- 只读；不修改他人日程。
- 结果仅展示演示所需的会议室名称与可用时段，不展开无关人员的完整日程。

## 10. 外部服务与降级边界

- 依赖服务：会议室查询 Mock
- 完整验收需要的权限：无真实会议室系统权限
- 缺失时允许的降级：无预置结果时只能告知无法查询，不得编造房间占用
- 降级时不得宣称：不得宣称已连接真实会议室系统；不得把查询结果说成已经预订

## 11. 验收标准

### AC-F005-01 查到明天下午 3 点后可用会议室

- Given：当前对话已打开，会议室查询结果已预置
- When：员工发送「查询明天下午 3 点以后可用的会议室」或从查询信息入口发出同一意图
- Then：中栏展示可用会议室结果；本轮为已回复
- 验证类型：agent

### AC-F005-02 只读且不创建会议

- Given：员工刚完成一次会议室查询
- When：查看本轮回复与事件流
- Then：不出现写操作确认单，不出现会议已创建，事件流为只读查询而非创建会议技能
- 验证类型：agent

### AC-F005-03 无可用时不编造预订成功

- Given：预置条件为该时段无可用会议室
- When：员工发出同一查询
- Then：明确无可用结果；不得展示会议已创建或已预订
- 验证类型：auto
