# F-001 维护独立对话上下文功能规格

## 1. 功能身份

- Feature ID：F-001
- 功能名称：维护独立对话上下文
- 所属版本：MVP
- 主要角色：员工（R-001）
- 来源需求：对话生命周期、BR-015
- 依赖 Feature：无
- 对应页面/视图候选：对话工作台（左栏会话 + 中栏对话）
- Spec 状态：Ready
- Spec 版本：1

## 2. 用户结果

员工能新建或切换自己的对话，在独立上下文里继续提问；旧对话的槽位和确认单不会带到新对话。

## 3. 前置条件与触发条件

- 前置条件：系统已注入演示身份林小北｜产品部；可存在若干预置对话便于演示
- 触发条件：员工进入对话入口、点击新建对话，或从最近对话中选择一条

## 4. 功能范围

### 包含

- 展示当前演示身份（林小北｜产品部）
- 查看属于自己的最近对话列表并切换
- 新建一条空上下文对话并成为当前对话
- 切换后只展示该对话已有消息，不携带其他对话的未完成槽位或确认单

### 不包含

- 登录、退出、切换成其他真人账号
- 查看或修改他人对话
- 知识问答、创建会议、周报、会议室查询的业务结果（分别由 F-002～F-005 验收）
- 评测与案例、预期路由、通过/不通过等 Demo 验证能力（F-006，非本 Feature）
- 删除对话、重命名对话的运营能力

## 5. 主流程

1. 员工进入对话入口，看到自己的身份和最近对话。
2. 员工新建对话：中栏为新的空上下文，可作为后续提问的当前对话。
3. 员工从最近列表选中另一条自己的对话：中栏恢复该对话已有内容，当前上下文改为该对话。
4. 员工在新对话中提问时，不得自动带出上一对话里未完成的会议时间、参会人或待确认单。

## 6. 异常与边界流程

- 当前没有任何最近对话：仍允许新建；列表为空不阻塞进入。
- 员工尝试访问不属于自己的对话：拒绝，不展示内容（MVP 仅一个演示身份，不得出现他人对话）。
- 上一对话停在待确认创建会议：切到新对话后，新对话不得沿用那张确认单去创建会议。

## 7. 业务规则与不变量

- BR-015：对话只属于当前演示身份；不得查看或修改他人会话
- 切换对话不把旧槽位带到新对话
- 演示身份全程为林小北｜产品部，本 Feature 不提供改身份

## 8. 业务数据读写

| 动作 | 业务对象 | 业务含义 | 数据 Owner |
|---|---|---|---|
| 读取 | 演示身份 | 展示姓名与部门 | 平台注入 |
| 读取 | 对话 | 列出并打开自己的对话 | F-001 |
| 创建 | 对话 | 新建空上下文 | F-001 |
| 修改 | 对话 | 将某条对话设为当前 | F-001 |

## 9. 权限、隐私与安全约束

- 无登录；身份由 Mock 注入，不可在本 Feature 内改成他人。
- 只能列出当前身份的对话。

## 10. 外部服务与降级边界

- 依赖服务：无真实账号服务；演示身份与对话列表预置或本地产生
- 完整验收需要的权限：无
- 缺失时允许的降级：无（缺失则无法进入工作台）
- 降级时不得宣称：不得宣称已对接飞书账号或组织通讯录

## 11. 验收标准

### AC-F001-01 新建对话得到空上下文

- Given：员工处于演示身份林小北｜产品部
- When：员工新建对话
- Then：当前对话为空上下文，中栏不出现其他对话的消息，也不出现其他对话的待确认会议
- 验证类型：agent

### AC-F001-02 切换对话恢复该对话内容且不串槽

- Given：对话 A 中存在未完成的会议槽位或待确认单，对话 B 为另一条自己的对话
- When：员工从 A 切换到 B，再在 B 中继续
- Then：B 不携带 A 的槽位和确认单；A 的待确认单不能在 B 中被用来创建会议
- 验证类型：agent

### AC-F001-03 只能看到自己的对话

- Given：系统仅注入林小北身份
- When：员工查看最近对话
- Then：列表中不出现其他员工的对话；无法打开他人对话
- 验证类型：auto

### AC-F001-04 身份可见

- Given：员工已进入对话入口
- When：员工查看工作台
- Then：能看到当前身份为林小北｜产品部
- 验证类型：agent
